# NetzaraBot

NetzaraBot is a Deriv-focused auto-trading product prototype.

It includes:

- Deriv data/research workflow
- paper-trading monitors
- strategy and rule reports
- live-candidate bot package
- MT5, Telegram, webhook, and mobile app export layers
- public website source for `www.netzarabot.com`
- Deriv OAuth/API backend route skeleton
- subscription/referral/profit-share business-model scaffolding

## Current Status

This project is still in staged rollout:

- Website is live.
- Deriv App ID is connected.
- Founder/free email is configured.
- Real Deriv trading backend routes exist.
- Token and demo trading must be tested before any real-money operation.
- Payment checkout link still needs to be connected.
- VPS trading engine still needs to be deployed.

## Important Safety Note

Do not commit real Deriv API tokens, payment secrets, SSH keys, VPS passwords, or customer credentials.

Use environment variables or secret storage for sensitive values.
